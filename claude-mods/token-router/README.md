# token-router — автовыбор модели и усилия для Claude Code

Мод для Claude Code. Перед каждым промптом он оценивает сложность задачи и сам выбирает модель и уровень усилия (effort): на «спасибо» не тратится Opus, а на архитектурную задачу не ставится Haiku. Модель переключается только тогда, когда это действительно экономит токены с учётом кэша.

## Как он решает

1. **Оценка сложности** — пять уровней: тривиальная, простая, средняя, сложная, очень сложная.
   - Сначала бесплатные правила на русском и английском: длина, наличие кода, слова вроде «рефактор», «миграция», «race condition», «переименуй», «что такое».
   - Короткие реплики вроде «да давай», «продолжай», «ок» оставляют уровень прошлой задачи: это продолжение, а не новая мелкая задача.
   - Если правила не уверены, задачу оценивает Haiku 5.5. Это стоит около $0.00005 за промпт.
2. **Уровень → модель и усилие:**

   | Уровень | Модель · усилие |
   |---|---|
   | тривиальная | Haiku 5.5 · low |
   | простая | Haiku 5.5 · medium |
   | средняя | Sonnet 5.5 · medium |
   | сложная | Opus 5.5 · high |
   | очень сложная | Opus 5.5 · xhigh (или Fable 5.1 · high, если разрешён) |

3. **Проверка окупаемости.** Кэш промптов привязан к модели, а смена effort тоже сбрасывает кэш сообщений. Поэтому при длинном контексте прыжок между моделями может стоить дороже, чем сэкономит. Мод считает:
   - **Повышение** (задача сложнее текущей настройки) делается всегда: слабая модель на сложной задаче обходится дороже переделками.
   - **Понижение** делается, только если ход на дешёвой модели вместе с перезаписью кэша выходит хотя бы на 15% дешевле. Учитывается размер контекста (по фактическому `usage` прошлого запроса) и то, прогрет ли ещё кэш у целевой модели.

   Пример: на «спасибо» в начале сессии мод уйдёт с Opus на Haiku. Если же Opus уже держит 400k токенов контекста, снижение effort с xhigh до high не сделает: перезапись кэша съест всю экономию.

Сабагенты не трогаются, у них своя настройка. Если сменить модель вручную через `/model`, мод это заметит и закрепит выбранную модель, пока не напишешь `/router auto`.

## Управление

- `@haiku`, `@sonnet`, `@opus`, `@fable`, `@low` … `@max` в тексте промпта переопределяют выбор на этот ход. Тег вырезается из промпта, например: `@opus @max почини гонку в воркерах`.
- `/router` — показывает статус, текущую модель, размер контекста и оценку экономии.
- `/router off` / `/router on` — выключить или включить роутер.
- `/router pin opus high` — закрепить модель и/или усилие, `/router auto` — вернуть автовыбор.
- `/router reset` — обнулить статистику.

Текущий выбор виден в статус-строке (`router: sonnet·medium · средняя`), при переключении появляется короткое уведомление.

## Настройки

Задаются в `/config`, в разделе плагина:

- **maxModel** — самая сильная модель, которую можно выбрать (по умолчанию `opus`; `fable` разрешит Fable 5.1 на очень сложных задачах). Если потолок ниже, чем нужно задаче, мод компенсирует это усилием на ступень выше.
- **minModel** — самая дешёвая модель (по умолчанию `haiku`).
- **classifier** — `auto` (правила + Haiku) или `rules` (только правила, без вызовов модели).
- **cacheTtlMinutes** — сколько минут кэш считается тёплым (по умолчанию 5).

## Установка

Из клона этого репозитория:

```bash
git clone https://github.com/artemius000/mark.git && cd mark
git checkout claude/tiktok-link-viewing-u1isfe
claude --plugin-dir ./claude-mods/token-router
```

Или поставить постоянно через локальный маркетплейс:

```bash
claude plugin marketplace add ./mark
claude plugin install token-router@artemius-mods
```

Когда ветка будет влита в `main`, хватит одной строки в терминальной сессии Claude Code:

```
/plugin install token-router --marketplace artemius000/mark
```

## Что важно знать

- Цены в расчётах — прайс-лист API Anthropic (Haiku 5.5 $0.10/$0.50, Sonnet 5.5 $2/$10, Opus 5.5 $4/$20, Fable 5.1 $10/$50 за 1M токенов). На подписке Pro/Max денег за токены нет, но лимиты расходуются примерно пропорционально, так что логика та же.
- Экономия в `/router` — оценка: те же токены посчитаны по цене модели сессии. Другая модель на той же задаче могла бы потратить другое число токенов.
- Если организация запрещает какую-то модель, сузьте диапазон через `minModel` / `maxModel`.
- API модов Claude Code в раннем доступе и может меняться между версиями. Мод проверен на Claude Code 2.1.296: `claude plugin validate`, проверка типов и 13 тестов (`claude plugin test`).
