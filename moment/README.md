# МОМЕНТ — концепт-лендинг премиального автосервиса

Дерзкий лендинг независимого ателье обслуживания Porsche, BMW M и Mercedes-AMG.
Главная идея: «Дилер вам этого не покажет». При прокрутке 3D-колесо разбирается
на шину, кованый диск, карбон-керамический тормоз и суппорт, и у каждой детали
показан реальный замер с допуском.

Компания, адрес, цены и статистика вымышлены, но лежат в реалистичных диапазонах.

## Стек

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4
- React Three Fiber + drei + postprocessing: процедурное колесо с текстурами на canvas (надписи на боковине, ламели протектора, карбон-керамика), зеркальный пол, студийный свет с бегущим бликом, bloom и виньетка. HDR не загружается.
- GSAP ScrollTrigger + SplitText: закреплённый разбор колеса, раскрытие кинокадра, горизонтальная лента услуг с параллаксом внутри карточек, построчные проявления заголовков
- Lenis: плавная прокрутка, синхронизированная с ScrollTrigger
- Framer Motion: прелоадер-динамометр, меню на весь экран, курсор, магнитные кнопки с прокруткой текста, пошаговая форма записи, счётчики

На слабых видеокартах сцена сама снижает плотность пикселей, а затем отключает зеркальный пол и постобработку (`PerformanceMonitor`). Телефоны получают облегчённую сцену сразу.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
STATIC_EXPORT=1 npm run build   # статический сайт в out/
```

## Структура

- `app/` — layout, шрифты (Roboto Flex в широком начертании, Cormorant Garamond italic, JetBrains Mono), токены
- `components/HeroScene.tsx` — закреплённый первый экран и сценарий разбора
- `components/three/` — сцена, свет, процедурное колесо, текстуры и раскладка под телефон/планшет/десктоп
- `lib/content.ts` — все тексты, цены и замеры в одном месте
